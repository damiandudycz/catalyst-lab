`list_operations` reports active work, completed or failed operation results still shown in the sidebar, queued builds, and whether the queue is paused. Use `open_operation` with an exact returned ID only when the user explicitly asks to open its view; this includes `op:`, `vm:`, and `queue:` IDs. Use `resume_build_queue` only when the user explicitly asks to start or resume queued work; it can automatically start the next build. Use `stop_operation` with the queue entry ID to remove a queued build. Distinguish queued, running, completed, failed, and stopped states.
